# FIFA Randomizer

Веб-приложение для случайного выбора футбольных команд из игр серии FIFA и EA SPORTS FC.

## Возможности

- Выбор версии игры: FIFA 22, FIFA 23, EA SPORTS FC 24, EA SPORTS FC 25, EA SPORTS FC 26
- Выбор типа команд: клубы или сборные (включая женские сборные)
- Фильтр по звёздам (рейтингу команды от 1 до 5 с шагом 0.5)
- Возможность выбрать несколько значений звёзд одновременно
- Два независимых блока для жеребьёвки
- Адаптивный дизайн для мобильных устройств

## Данные

Файл `TEAMS.json` содержит информацию о более чем 1500 командах из пяти версий игры:

- Клубы из топ-лиг: АПЛ, Ла Лига, Бундеслига, Серия А, Лига 1, Эредивизи, Лига Португал, MLS, Liga MX, Саудовская лига
- Мужские и женские сборные всех конфедераций
- Рейтинг команд (звёзды) на основе общего рейтинга в игре

Примечание: рейтинг звёзд является приблизительной оценкой, поскольку EA не публикует официальную таблицу звёзд для всех команд и версий.

## Использование

1. Выберите версию FIFA, нажав на соответствующую кнопку.
2. Выберите тип команд: клубы или сборные.
3. Выберите одну или несколько звёзд (рейтинг команды).
4. Нажмите Randomize в блоке Team One или Team Two.
5. На экране появится случайная команда, соответствующая выбранным фильтрам.
