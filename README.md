# ⚽ FIFA Randomizer

Сайт для случайного выбора футбольных команд из игр серии FIFA и EA SPORTS FC.

## 🌟 Возможности

- Выбор версии игры: от **FIFA 22** до **EA SPORTS FC 26**
- Выбор типа команд: **Клубы** или **Сборные** (включая женские сборные)
- Гибкий фильтр по **звёздам** (рейтингу команды от 1 до 5 с шагом 0.5)
- Возможность выбрать **несколько значений звёзд** одновременно
- Два независимых блока для жеребьёвки: **Team One** и **Team Two**
- Адаптивный дизайн — удобно использовать на телефонах и планшетах

## 🗃️ Данные

В проекте используется файл `TEAMS.json`, который содержит информацию о:
- 1500+ командах из 5 версий игры (FIFA 22, FIFA 23, EA SPORTS FC 24, EA SPORTS FC 25, EA SPORTS FC 26)
- Клубах из топ-лиг: АПЛ, Ла Лига, Бундеслига, Серия А, Лига 1, Эредивизи, Лига Португал, MLS, Liga MX, Саудовская лига
- Мужских и женских сборных всех конфедераций
- Рейтинге команд (звёзды) — оценка на основе общего рейтинга в игре

> **Важно:** Рейтинг звёзд — это приблизительная оценка, так как EA не публикует официальную таблицу звёзд по всем командам и версиям.

## 🚀 Как использовать

1. **Выберите версию FIFA** — нажмите на одну из кнопок: `FC 26`, `FC 25`, `FC 24`, `FIFA 23`, `FIFA 22`
2. **Выберите тип команд** — `Club Teams` или `International Teams`
3. **Выберите звёзды** — нажмите на одну или несколько кнопок с рейтингом (можно выбрать несколько значений)
4. **Нажмите Randomize** — в блоке Team One или Team Two появится случайная команда, соответствующая выбранным фильтрам
